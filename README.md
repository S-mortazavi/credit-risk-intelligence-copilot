# Credit Risk Intelligence Copilot

An end-to-end AI system for credit risk analysis combining machine learning,
model explainability, retrieval-augmented generation (RAG), and agentic LLM
workflows.

## Objectives

The system will progressively support:

- Probability of Default (PD) estimation
- Model calibration
- Local and global model explainability
- Natural-language risk explanations
- Retrieval-Augmented Generation (RAG)
- Context-aware credit risk analysis
- Agentic workflows and tool calling
- LLM evaluation and observability

## Dataset

This project uses the Home Credit Default Risk dataset.

Raw datasets are not stored in this repository.

Place downloaded dataset files under:

`data/raw/`
